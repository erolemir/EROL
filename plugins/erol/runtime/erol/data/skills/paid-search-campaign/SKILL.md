# Paid Search Campaign

Design paid-search campaign drafts with intent separation, budget boundaries and reliable conversion measurement.

## Workflow

1. Confirm business outcome, geography, offer and authorized budget; draft campaigns without activating spend unless explicitly requested.
2. Group buyer intent and negatives using current search evidence; avoid mixing brand, prospecting and remarketing results as if they were comparable.
3. Align ads, keywords and landing-page promises; verify current platform eligibility, settings and conversion semantics through official documentation/account evidence.
4. Define capped tests, decision windows and stop conditions; forecast using explicit assumptions rather than guaranteed cost or return.

## Verification

Validate destination, offer claims, event firing/deduplication and budget settings before any authorized launch; report draft versus live status.

## Deliverable

Campaign structure, ad variants, budget/stop rules and tracking checks.

## Current reference

Verify platform-specific details against [official documentation](https://support.google.com/google-ads/answer/6167115) for the deployed version.
