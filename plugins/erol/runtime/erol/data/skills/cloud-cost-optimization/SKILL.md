# Cloud Cost Optimization

Reduce cloud spend using attributable usage, unit costs and reversible capacity decisions.

## Workflow

1. Attribute charges to services, environments and billing periods; distinguish list prices, committed charges and usage-dependent costs.
2. Measure workload demand and reliability requirements before rightsizing; include storage, egress and observability charges.
3. Rank reversible savings by expected impact and confidence; account for migration effort and contractual commitments.
4. Do not delete resources or purchase commitments merely because a report recommends them; retain the task's authorization and rollback scope.

## Verification

Compare unit costs and reliability across equivalent workloads; use current provider billing evidence and disclose forecast uncertainty.

## Deliverable

Cost attribution, prioritized changes and verification/rollback plan.
