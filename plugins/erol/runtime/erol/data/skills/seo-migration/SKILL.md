# Seo Migration

Plan URL or domain migrations with preserved destinations, redirects and post-move search monitoring.

## Workflow

1. Inventory important old URLs and their intended replacement or removal outcome, including assets and high-value entry pages.
2. Prepare a destination map and appropriate redirects; update canonicals, internal links and sitemaps together.
3. Stage and validate the new site before authorized cutover; avoid combining unrelated redesigns with a URL move unless required.
4. Monitor old/new discovery, errors and traffic with a recovery owner; disclose that search outcomes can vary after a move.

## Verification

Test representative old-to-new paths, redirect loops/chains, removed pages and destination indexability; compare post-move evidence with a dated baseline.

## Deliverable

URL map, cutover/recovery plan and migration checks.

## Current reference

Verify platform-specific details against [official documentation](https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes) for the deployed version.
