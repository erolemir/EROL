# Landing Page Optimization

Improve landing pages through message/offer alignment, user friction and measured conversion hypotheses.

## Workflow

1. Inspect traffic intent, page promise and conversion definition; use existing user evidence and analytics before diagnosing friction.
2. Align headline, proof, offer conditions and primary action; keep essential information and avoid deceptive urgency or hidden costs.
3. Check mobile, accessibility, form recovery and page loading as practical barriers, not just visual preferences.
4. Create a focused variant with a falsifiable hypothesis and consistent tracking rather than changing every element at once.

## Verification

Verify the action path and claims, exercise representative devices, then compare suitable cohorts with guardrails when a test is authorized.

## Deliverable

Prioritized findings, page/copy variant and measurement criteria.
