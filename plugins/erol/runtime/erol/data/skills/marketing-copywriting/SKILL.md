# Marketing Copywriting

Write truthful campaign or product copy matched to audience intent, channel constraints and a clear action.

## Workflow

1. Identify audience, offer, awareness level and desired action; use the actual product facts and brand constraints.
2. Lead with a concrete outcome and explain how the offer supports it; make the next action and material conditions clear.
3. Create a small set of meaningfully different message angles rather than superficial synonym changes.
4. Check substantiation, channel length and current relevant platform policies. Never invent testimonials, scarcity, endorsements or performance numbers.

## Verification

Review each claim and offer condition, compare variants against the same objective and mark any performance assumption awaiting a test.

## Deliverable

Ready-to-review copy variants and their intended audience/angle; publishing is a separately authorized action.
