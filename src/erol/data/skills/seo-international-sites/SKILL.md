# Seo International Sites

Design localized URL discovery, alternate-language annotations and consistent international page targeting.

## Workflow

1. Map intended language/region audiences to actual localized pages and stable URLs; keep targeting separate from automatic browser redirection.
2. Verify annotation format and reciprocal relationships using current search documentation; align each set with canonical/indexable pages.
3. Check discovery and language consistency across navigation, page content and fallbacks without assuming country and language are interchangeable.
4. Handle missing localized content deliberately; do not declare incomplete placeholders as equivalent alternatives.

## Verification

Crawl representative alternate sets and verify reciprocal URLs, response status and rendered language; monitor regional performance separately.

## Deliverable

Locale/URL map, annotation fixes and representative crawl checks.

## Current reference

Verify platform-specific details against [official documentation](https://developers.google.com/search/docs/specialty/international/localized-versions) for the deployed version.
