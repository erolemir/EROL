# Product Prioritization

Prioritize product work using customer evidence, constraints and transparent impact assumptions.

## Workflow

1. Name the business/user objective, constraints and nonnegotiable obligations; gather actual problem frequency and consequence evidence.
2. Compare options using compatible impact, effort and confidence assumptions; scoring frameworks support judgment rather than creating certainty.
3. Account for dependencies, reversibility and learning value; distinguish small discovery tests from committed implementation.
4. Define the evidence and time horizon for revisiting priorities, preserving explicit commitments and capacity limits.

## Verification

Trace each ranking to its inputs, inspect sensitivity to uncertain estimates and identify a falsifiable completion/outcome criterion.

## Deliverable

Prioritized options, assumptions and revisit conditions.
