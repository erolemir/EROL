# Lifecycle Email Marketing

Design permission-aware lifecycle emails triggered by meaningful product states and measured user outcomes.

## Workflow

1. Map lifecycle state, message purpose, permitted recipients and consent/suppression sources before defining a sequence.
2. Use product behavior to trigger relevant messages; separate transactional obligations from promotional content.
3. Define frequency caps, unsubscribe handling, invalid-address suppression and state-change cancellation; prevent replayed events sending duplicate mail.
4. Draft useful messages with honest claims and clear actions; actual sending requires explicit task authorization and applicable policy verification.

## Verification

Simulate entry/exit states, unsubscribe, duplicate events and frequency caps; validate links and outcome tracking beyond opens alone.

## Deliverable

Lifecycle map, reviewed drafts and delivery/suppression test cases.
