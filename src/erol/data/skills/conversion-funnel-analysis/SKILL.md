# Conversion Funnel Analysis

Analyze conversion funnels with consistent identities, event ordering and meaningful denominators.

## Workflow

1. Define user/account unit, eligibility, time window and ordered steps; document whether repeats and cross-device identities merge.
2. Check event completeness, deduplication and ordering before interpreting dropoff; separate tracking loss from user behavior.
3. Segment by relevant entry context and cohort while avoiding tiny or incomparable slices.
4. Form a few testable explanations for the largest verified bottleneck rather than redesigning every step from aggregate percentages.

## Verification

Reconcile step counts to sample journeys and validate denominator/time-window consistency; state data coverage and identity uncertainty.

## Deliverable

Reproducible funnel, evidence-backed hypotheses and next test.
