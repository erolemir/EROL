# Seo Technical Audit

Audit crawlability, rendering, canonical URLs and index eligibility from page and search evidence.

## Workflow

1. Inventory important URLs, page templates and intended indexable content; collect permitted crawl, render and Search Console evidence.
2. Inspect response status, robots directives, canonical choices, sitemaps and internal discovery paths together; separate crawl blocking from indexing control.
3. Check what users and crawlers can actually render, including JavaScript routes, pagination and duplicate filter URLs.
4. Prioritize demonstrated technical blockers by affected templates and business value; avoid ranking guarantees or blanket sitewide changes.

## Verification

Recheck representative URLs after changes and document observable fixes separately from later search-performance outcomes.

## Deliverable

Template-level findings with URL evidence, bounded fixes and recheck results.
